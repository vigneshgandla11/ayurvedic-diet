## Ayurvedic Diet Planner

A web application built with Python Flask, HTML, CSS and SQLite.

### Features
- Takes user health data as input
- Calculates BMI automatically
- Gives personalized Ayurvedic diet recommendations
- Stores patient records in SQLite database

### Technologies Used
- Python (Flask)
- HTML, CSS
- SQLite

### How to Run
1. Clone this repo
2. Run: pip install flask
3. Run: python app.py
4. Open browser and go to http://localhost:5000
